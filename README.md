## 液态玻璃的性能取舍（重要）

真玻璃 = `backdrop-filter` 真实背景模糊 + 镜面棱边高光。每个开真模糊的元素都在实时重采样背景，滚动中几十个一起采样会卡。

所以：

- **固定层**（顶栏、底栏、详情面板）→ 用真模糊，视觉收益最大且不动
- **滚动区卡片** → 用光学模拟（渐变面 + 棱边高光 + 内辉光），零采样成本
- 设置里有 **「极致玻璃」** 开关，打开后卡片也上真模糊 —— 在真机上自己测流畅度，卡就关掉

背景那三层蓝色光晕不是装饰，是让模糊有东西可折射，玻璃才"真"。设置里可关掉省电。

## 加功能往哪写

1. 在 `features.js` 的 `FEATURES` 里 `add({...})`：声明 `name/desc/cat/icon/tags/fields/compute`
2. `fields` 支持 `number / text / textarea / select / date / time / checkbox`，`showIf` 控制条件显隐
3. `compute(v)` 返回结果数组：`{label, value}`，加 `primary:true` 放大显示，加 `mono:true` 等宽，加 `copy:true` 点击复制，加 `section:true` 当小标题
4. 需要复杂交互（不是表单能表达的）就写 `custom: '名字'`，在 `app.js` 的 `renderCustom` 里实现
5. 新分类要加进 `app.js` 的 `CAT_ORDER`

## 部署
