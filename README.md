# AI Lab · 跑在 iPad 本地的 AI 与传感器游乐场

用 Safari「添加到主屏幕」当 App 用。**神经网络、遗传算法、博弈搜索、图像处理全部是从零手写的 JavaScript；摄像头和麦克风的数据只在你设备内存里处理，一帧都不出设备，不联网、无后端、无第三方库。**

**线上地址：https://ntzabc.github.io/my-ipad-webapp/**

## 神经进化模拟的两阶段设计

这是这一轮改动最大的部分：

1. **布置阶段** —— 用手指在画布上画出**任意弯曲的障碍线**。笔画数量、长度都不设上限（旧版本是方块、而且超过 14 块就自动删最早的）。
2. **点「开始进化」** —— 障碍立刻锁定，虫子开始跑。想改障碍必须点「重新布置」。

食物任何阶段都能放，而且**你亲手摆的食物不会被系统清掉**。

**5 套内置场地预设**（空旷平原 / 峡谷 / 迷宫走廊 / 漏斗 / 立柱阵），每套预定义了布局 + 参数（种群、世代长度、食物数、变异率）。**3 档难度**。自己画的布局可以**保存到本机**，下次「读取布局」直接恢复。

## 跑测试

```bash
node tests/ai.test.js
node tests/sense.test.js
node tests/consistency.test.js
```

**299 项，改完代码必跑。** 里面有硬指标，不是走过场：

- **梯度校验**：反向传播的解析梯度 vs 数值梯度，偏差必须 < 1e-5（当前 1.6e-10）
- **XOR 收敛**：训练后准确率必须 > 90%
- **进化有效性**：30 代后觅食能力必须强于第一代，且过程可复现
- **读心有效性**：对循环出拳的预测命中率必须 > 60%
- **视觉算法**：肤色判定、色相追踪、亮点追踪必须能在一张合成图上定位到正确位置
- **一致性检查**：没有浏览器也能查选择器写错、kit 方法名写错、CSS 类漏定义、**清理函数漏写**

算法错不会崩，只会**安静地给你错的结果** —— 所以这些必须过。

## 液态玻璃的三档

`backdrop-filter` 糊的是**背景里的高频细节**。背景是纯色渐变时无细节可糊，开关按下去自然没反应。**所以背景铺了几百个粒子，粒子就是玻璃的燃料。**

| 档位 | 卡片 | 效果 |
|---|---|---|
| 流畅 | 无背景模糊 | 粒子是清晰的点，零采样开销 |
| 标准 | `blur(13px) saturate(175%)` | 粒子变成柔和光斑 |
| 极致 | `blur(34px) saturate(330%) brightness(1.30)` + 底色压到几乎透明 | 粒子被糊成大片流动色块 |

设置页有两块**实物对照**，不用切档就能看出差别。

## 性能设计

- 粒子数按屏幕面积算，**帧率自适应**：连续掉帧自动减量，恢复了再加回来
- 粒子画布像素比封顶 2；连线按透明度分 6 档批量描边；禁用 `shadowBlur`
- 玩法面板打开时粒子降到 30fps（模糊底图不必每帧重采样）
- 标签页切到后台自动暂停
- 摄像头处理都在低分辨率小画布上做（图像 224×168、追踪 160×120）
- 音高检测用抽取降采样，把自相关的计算量压到 1/4
- **每个玩法关闭时都会调用自己返回的清理函数**，停掉 rAF / 摄像头 / 麦克风

## 摄像头的前提（重要）

- 必须 **HTTPS**（GitHub Pages 已满足）
- 必须由你**点一下按钮**才允许 —— iOS 强制要求
- 在「添加到主屏幕」的独立 App 模式下，iOS 对 `getUserMedia` 历史上有限制。**如果摄像头在独立模式下打不开，用 Safari 直接打开网址就能用**（裸眼 3D 还有手指拖动和重力感应两条退路）
- 画面只在设备内存里逐像素处理，不录制、不上传、不落盘

## 加玩法

`features.js` 里 `add({...})`，或 `features-cam.js` 里 `F.push({...})`：

- `kit` 提供 `AI`（算法库）、`el(tag, cls, text)`、`stat(parent, label, value)`、`makeCanvas(parent, aspect)`、`toast(msg)`
- `makeCanvas` 返回 `{ cv, ctx, w, h }`，已处理 DPR 与旋转
- **`render` 必须返回清理函数**，否则关掉面板后摄像头 / 循环还在跑
- 新分类要加进 `app.js` 的 `CAT_ORDER`
- 写完跑 `node tests/consistency.test.js`，它会检查清理函数有没有漏
