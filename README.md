# AI Lab · 跑在 iPad 本地的 AI 游乐场

用 Safari「添加到主屏幕」当 App 用。**所有神经网络、进化算法、博弈搜索都是从零手写的 JavaScript，不联网、不调用任何外部服务、不上传任何数据。** 你手里的 iPad 就是全部算力来源。

**线上地址：https://ntzabc.github.io/my-ipad-webapp/**

## 5 个玩法

| 玩法 | 里面真正在跑什么 |
|---|---|
| **神经网络实验室** | 手写多层感知机 + 反向传播（tanh 隐层 / sigmoid 输出 / 交叉熵）。5 种二维数据集可选，实时看决策边界被学出来；网络结构图会跟着你的手指亮起各层激活 |
| **神经进化模拟** | 44 只小虫各有自己的神经网络大脑，靠遗传算法（精英保留 + 交叉 + 高斯变异）一代代进化出觅食能力。可以往场上投放食物和障碍 |
| **AI 读心猜拳** | 6 个预测专家 + 指数加权（Hedge）在线集成。它一边跟你玩一边摸你的出拳规律，还会输出一份"你输了之后 78% 会出剪刀"式的习惯报告 |
| **反转棋 AI** | minimax + alpha-beta 剪枝 + 位置权重表 + 落子排序。三档难度（搜索深度 1 / 3 / 5） |
| **AI 寻路竞技场** | BFS / A\* / 贪心最优优先三种搜索同场竞技，对比路径长度与探索格子数，并动画回放搜索过程 |

## 跑测试

```bash
node tests/ai.test.js           # 算法：梯度校验、收敛、棋力、学习率
node tests/consistency.test.js  # 选择器 / kit 方法 / CSS 类 / 清理函数
```

`ai.test.js` 里有几项是**必须**过的硬指标：

- **梯度校验**：解析梯度 vs 数值梯度，偏差 < 1e-5。梯度错了训练就是瞎走
- **XOR 收敛**：训练后准确率必须 > 90%
- **进化有效性**：30 代后觅食能力必须比第一代强
- **读心有效性**：对循环出拳的预测命中率必须 > 60%

改了 `ai.js` 一定要重跑。这些算错不会崩，只会**安静地给你错的结果**。

## 液态玻璃的三档（这是这套界面最核心的设计）

`backdrop-filter` 模糊的是**背景里的高频细节**。背景如果是纯色渐变，没有任何细节可糊 —— 这就是为什么很多"玻璃"开关按下去没反应。

所以这里的做法是：**背景铺几百个粒子，粒子就是玻璃的燃料**。

| 档位 | 卡片 | 看到的效果 |
|---|---|---|
| 流畅 | 无背景模糊 | 粒子是清晰的点，零采样开销 |
| 标准 | `blur(13px) saturate(175%)` | 粒子变成柔和光斑 |
| 极致 | `blur(34px) saturate(330%) brightness(1.30)` + 底色压到几乎透明 | 粒子被糊成大片流动色块，镜面棱边高亮 |

设置页里有两块**实物对照**（同一位置、同样背景，一个 plain 一个 ultra），不用切档就能看到差别。

其余性能设计：
- 粒子数按屏幕面积算，帧率自适应（连续掉帧自动减量，恢复了再加回来）
- 粒子画布像素比封顶 2；连线按透明度分 6 档批量描边；禁用 `shadowBlur`
- 玩法面板打开时粒子降到 30fps（模糊底图不必每帧重采样）
- 标签页切到后台自动暂停
- 每个玩法关闭时都会调用自己返回的清理函数，停掉 rAF / interval

## 加玩法

在 `features.js` 里 `add({ id, name, cat, desc, tags, icon, render(root, kit) })`。

- `kit` 提供：`AI`（算法库）、`el(tag, cls, text)`、`stat(parent, label, value)`、`makeCanvas(parent, aspect)`、`toast(msg)`
- `makeCanvas` 返回 `{ cv, ctx, w, h }`，已处理 DPR 和旋转，尺寸变化会触发你注册的回调
- **`render` 必须返回清理函数**，否则关掉面板后循环还在跑，iPad 会烫
- 新分类要加进 `app.js` 的 `CAT_ORDER`
- 写完之后跑 `node tests/consistency.test.js`，它会检查清理函数有没有漏
