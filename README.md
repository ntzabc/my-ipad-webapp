# AI Lab

跑在 iPad 浏览器里的一整套 AI 玩法。**纯静态站，没有后端，没有构建步骤，不联网调用任何外部服务。**

用 Safari 打开 → 分享 → 添加到主屏幕，就会得到一个全屏、无地址栏、断网也能开的桌面图标。

**线上地址：** https://ntzabc.github.io/my-ipad-webapp/
**仓库：** https://github.com/ntzabc/my-ipad-webapp

---

## 一句话原则

**不拿"AI"当幌子。** 这里没有调用任何云端模型，所有神经网络、遗传算法、图像处理、音频分析都是本仓库里手写的 JavaScript，跑在你自己设备的 CPU 上。整个站点不发出任何网络请求（除了它自己的静态文件）。

## 文件结构

```
index.html            外壳骨架
style.css             深蓝液态玻璃 + 粒子背景 + iPad 断点适配
manifest.webmanifest  PWA 清单（display:standalone 才会全屏无地址栏）
sw.js                 离线缓存（改完静态资源记得把 CACHE 版本号 +1）
make_icons.py         纯标准库生成 PNG 图标，不依赖任何第三方库

ai.js                 算法层：MLP / 反向传播 / 遗传算法 / 在线集成 / 图搜索
sense.js              传感器层：摄像头与麦克风的封装 + 纯算法
vision.js             图像分析层：边缘 / 霍夫 / 区域分割 / 浮雕
particles.js          粒子背景
features.js           AI 类玩法的界面
features-cam.js       摄像头与声音类玩法的界面
app.js                外壳：标签页 / 搜索 / 全屏面板 / 偏好设置

tests/                见下
```

### 架构上的三条铁律

1. **`ai.js` / `sense.js` / `vision.js` 只放纯算法，绝不碰 DOM。**
   这样才能用 Node 直接跑测试。界面代码里出现算法，测试就废了。

2. **每个玩法的 `render(root, kit)` 必须返回清理函数。**
   关掉面板时会调用它。不返回的话，摄像头指示灯会一直亮、麦克风一直录音、
   rAF 循环一直跑 —— iPad 会烫、会掉电。`tests/consistency.test.js` 会强制检查这一条。

3. **玩法面板是全屏固定的（`inset: 0`）。**
   进入功能就是满屏，不靠手势去拉。只有"选择玩法"那一层可以滚动。

```bash
npm install          # 只为装 jsdom（冒烟测试需要）
npm test             # 一次跑完全部
```

```bash
node tests/ai.test.js
node tests/sense.test.js
node tests/vision.test.js
node tests/consistency.test.js
node tests/smoke.test.js
```

`smoke.test.js` 是这里最值钱的一套。它做两段：

- **设备被拒绝**：摄像头和麦克风都抛 `NotAllowedError`，验证界面给得出人能看懂的原因。
- **设备可用**：喂进合成的"人脸帧"和假音频信号，把整条链路真的跑起来 ——
  肤色定位头部 → 估计眼部区域 → 驱动视差；七种视觉算法逐帧处理；
  采样 → 训练 → 预测；频谱 → 音高 → 拍手。

**这套测试抓到过真 bug**，都是"不报错、只是安静地不工作"的那种：

- `MLP.trainBatch` 收的是 `[[输入, 目标], ...]` 数组对，代码里传了 `{x, y}` 对象
  → 前向拿到 `undefined` → 实时学习机整块假死
- 关面板有 380ms 退场动画，用户在这段时间内点开下一个玩法，
  上一个的清理定时器会把新面板清成一片空白
- 隐藏的 `<video>` 在 Safari 里不解码帧，`drawImage` 抓到全黑
  → 必须用"挪出屏幕"而不是 `display: none`
- 前置摄像头预览是镜像的，追踪点位置要水平翻转才对得上
- `AudioContext` 在 `await getUserMedia` 之后才 `resume`，iOS 会拒绝
  → 上下文永远是 `suspended`，analyser 全返回 0，表现就是"授权了但没声音"

## 已知限制

- **摄像头 / 麦克风必须 HTTPS**，而且必须由用户点击触发（iOS 强制）。
- **独立 App（加到主屏幕）模式下 iOS 对 `getUserMedia` 历史上有限制。**
  如果某个摄像头玩法打不开，先用 Safari 直接打开网址试试 —— 这能区分是
  "模式限制"还是"代码问题"。声控实验室里的「诊断」按钮会把每一环的状态列出来。
- **眼动追踪是粗粒度的。** 160×120 的画面做不了真正的瞳孔追踪，
  这里做的是"眼睛所在区域"的估计，用于让人机交互更灵敏，不是精确注视点。
- **所有计算都在设备上。** 传大图进 3D 重建时会先缩到 236px 宽再分析，
  否则 iPad 上会卡。

## 部署

推送到 `main` 分支即可，GitHub Pages 会自动发布。

```bash
git add -A
git commit -m "..."
git push
```

两个必须记住的坑：

1. **改了任何静态资源，把 `sw.js` 里的 `CACHE` 版本号 +1**，否则 iPad 会一直读旧缓存。
2. **加了新的 js 文件，要同时加进 `index.html` 和 `sw.js` 的 `ASSETS`**，
   `tests/consistency.test.js` 会检查这件事。

加主屏幕必须用 **Safari**，Chrome 或微信内置浏览器不行。
